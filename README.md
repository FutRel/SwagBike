## SWAG-bike — приложения для вело-поездок

Данный проект является финальной частью прохождения курса IT School Samsung и представляет собой приложение для ОС Android на Java с использованием API Google Maps (учебная версия), ныне не актуальный.

Приложение служит для записи, сохранения и просмотра записей поездок с помощью карты. Существует возможность начать поездку, поставить ее на паузу, посмотреть длительность и дистанцию поездки, активировать "отслеживание направления движения", а также управлять картой и перемещать ее. После остановки записи можно посмотреть все совершенные поездки, а также отсортировать их по различным параметрам. После открытия определенной записи на карте будет отображены старт и финиш поездки, пройденный маршрут, а также его длительность, расстояние и средняя скорость.

Приложение полезно для спортсменов, которым важно проанализировать свои результаты и сделать соответствующие выводы, или для туристов, которым важно запомнить и записать свои маршруты, чтобы, например, делиться ими со знакомыми или просматривать из вечерами.

Проект находится в стадии заморозки и поиска подходящего API карт.

Также планируется развивать данное приложение дальше, ближайший план - создание ссылок на поездки и просмотр поездок других людей, а также переход на векторную графику.
